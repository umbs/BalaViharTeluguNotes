# References & Useful Links

websites, videos, dictionaries, and other Telugu educational organizations we can
learn from and collaborate with.

> This is a shared, evolving document. Add anything useful you come across, keep
> entries in the right section, and add a one-line note on *why* it's useful.
> For local source materials (PDFs, DOCX, PPTX) used to author this content, see
> the [`reference/`](reference/) folder instead.

## How to contribute

- Add a bullet under the most fitting section with the link and a short note.
- Prefer stable, official links; verify a link works before adding it.
- If unsure of the exact URL, add the name + note and mark it `(link TBD)`.
